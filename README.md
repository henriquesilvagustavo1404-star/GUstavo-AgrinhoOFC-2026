# Simulador de irrigação inteligente.

O SoloTec é um sistema de irrigação inteligente que monitora a umidade do solo pelo celular. Com sensores no campo, o aplicativo mostra áreas verdes (úmidas), amarelas (quase secas) e vermelhas (secas), permitindo irrigação automática, agendamento e histórico completo. O objetivo é economizar água, reduzir custos e aumentar a produtividade.

# Objetivo 

O site foi criado para implementar uma ideia de irrigação inteligente feita pelo celular, ajudando a reduzir o desperdício de água e os custos com energia. Reduzir o desperdício de água ajudará o meio ambiente e permitirá produzir mais em pouco espaço, preservando as florestas.
